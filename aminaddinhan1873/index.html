Let’s open the book

This site reads the book’s text from a companion file called corpus.json. Your browser didn’t let the page load it automatically — that’s normal when you open the page straight from your computer.

Want it to load on its own every time?

Put index.html and corpus.json in the same folder, run this command in that folder, then visit localhost:8000. On a normal web server it just works.

python3 -m http.server 8000

    About this book

    What it is, where it comes from, and what you’ll see on each page.

    The book

    Matla‘ al-‘Ajā’ib (مطلع العجائب) is an Urdu book by Amīn al-Dīn Khān. It was printed in 1873 in Lucknow by the Munshi Naval Kishore Press, one of the biggest publishers in 19th-century India. It was made as a lithograph — printed from hand-written plates, which is why the script looks like calligraphy.

    The original copy belongs to Heidelberg University Library in Germany, which photographed every page and shares the images online.

    What you’ll find on each page

    The picture

    A photo of the real page from the library’s copy. You can zoom in, move around, rotate it, or boost the contrast to make faint ink easier to see.

    What the page is about

    A short summary in plain English, so you can follow along without reading Urdu.

    The Urdu text

    Every line typed out exactly as it’s printed, so you can read, search and copy it. (Researchers call this a “diplomatic transcription” or “ground truth”.)

    Roman Urdu

    The same lines written in Latin letters (transliteration), so you can sound the words out even if you don’t read the Urdu script. It’s not a translation.

    People & places

    Names that come up on the page. Click one to find every other page that mentions it.

    Searching

    Search works in English, in Urdu script and in Roman Urdu. You don’t need to type accents or special marks — ajaib finds ʿajāʾib. Put words in quotes, like "Naval Kishore", to find an exact phrase. Type a number to jump straight to that page.
