    IIAbout the project

    Reading, reuse & citation

    What an edition offers

    Each work opens in its own reading room, with the scanned page on one side and the transcribed text on the other.

    • Zoomable facsimile, streamed from the library that holds the original
    • Diplomatic, line-by-line transcription in the original script
    • Transliteration, English digest and entity index, where available
    • Full-text search, plain-text & JSON export, and citable page links
